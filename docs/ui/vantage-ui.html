Vantage UI
    Design system · Competitive tactical FPS

    The interface that gets out of the fight.

    VANTAGE UI is an original, esports-ready interface language: minimal, fast, and readable under pressure. Every color carries meaning, every readout is tabular, and every pixel is spent on the information a player needs mid-duel — nothing else.

    Readability-first 8-pt grid · 4–8px radii Theme-aware 16:9 → 32:9 · Steam Deck → 8K Accessibility built-in

    Color system

    Neutrals with a cool bias do the quiet work; a single warm accent owns "your action". Semantic colors are kept separate from the accent so state never has to fight the brand.

    Grid, spacing & radius

    One 8-point rhythm everywhere. Corners stay between 4 and 8px — soft enough to feel modern, tight enough to feel engineered.

    Icon library

    Original single-weight geometric glyphs on a 24px grid — one stroke, rounded joins, no fill. Built to read at 18px in the HUD and 26px in menus.

    Scoreboard

    08

    Animation language

    Motion communicates, never decorates. Everything is fast (≤200ms), purposeful, and fully disabled under prefers-reduced-motion.

    09

    Accessibility framework

    Not a settings tab bolted on at the end — a foundation. State is never carried by color alone, motion is opt-out, and the crosshair is fully player-authored. Try the editor.
